There is no standing bootstrap admin: a brand-new install has no accounts, so
first boot prints a one-time setup token to the pod's logs instead of a
default login. Find it with:

  kubectl logs deploy/{{ include "cinc-dashboard.fullname" . }} | grep -A2 "no accounts exist yet"

Visit /setup with that token to create the first account, granted Platform
Admin -- the token stops working the moment the pod restarts if it isn't
used first. From there, add more servers, collectors, accounts, and role
grants from the admin UI (/admin).
